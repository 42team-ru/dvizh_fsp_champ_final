# Карта

Карта ленты, карта моих встреч и выбор места в форме мероприятия. Два движка 2ГИС — RasterJS и MapGL —
спрятаны за одним адаптером; снаружи координаты всегда `[lon, lat]`.

---

## 1. API

```
GET /api/events/map?minLon=92.7&minLat=55.9&maxLon=93.1&maxLat=56.1
                   &from=2026-10-20T00:00:00Z&to=2026-10-27T00:00:00Z
                   &sportId=…&level=BEGINNER&joinMode=FREE&searchText=бег
```

| Параметр                                     | Обязателен | Что                                                              |
|----------------------------------------------|------------|------------------------------------------------------------------|
| `minLon`, `minLat`                           | да         | юго-западный угол экрана                                         |
| `maxLon`, `maxLat`                           | да         | северо-восточный угол                                            |
| `from`                                       | нет        | ISO-время, по умолчанию «сейчас»; прошлое заменяется на «сейчас» |
| `to`                                         | нет        | по умолчанию `from + 30 дней`                                    |
| `searchText`, `sportId`, `level`, `joinMode` | нет        | как в ленте                                                      |

- Отдаются опубликованные очные мероприятия с точкой внутри области и началом в окне.
- Онлайн-встреч на карте нет, поэтому фильтра `format` нет. Встреча уровня «Любой» подходит под любой
  фильтр уровня.
- Кластеры бэкенд не считает — группирует фронт.
- Максимум 1000 точек, ближайшие по времени; если в области больше — `truncated: true`.
- `minLon > maxLon` — не ошибка: это область через 180-й меридиан (Чукотка), бэкенд ищет в двух
  прямоугольниках.
- `400`: нет области, значения вне диапазона, `minLat > maxLat`, `to` раньше `from`.

Ответ — стандартный GeoJSON:

```json
{
  "type": "FeatureCollection",
  "truncated": false,
  "limit": 1000,
  "features": [
    {
      "type": "Feature",
      "id": "a81c3d24-…",
      "geometry": {
        "type": "Point",
        "coordinates": [
          92.88194,
          56.00784
        ]
      },
      "properties": {
        "id": "a81c3d24-…",
        "title": "Утренняя пробежка по набережной",
        "sport": {
          "id": "…",
          "name": "Бег",
          "slug": "running",
          "custom": false
        },
        "startAt": "2026-10-21T00:00:00Z",
        "endAt": "2026-10-21T01:00:00Z",
        "address": "Красноярск, ул. Дубровинского, 1, набережная у Речного вокзала",
        "level": "BEGINNER",
        "joinMode": "FREE",
        "participantsCount": 2,
        "capacity": null,
        "myRegistrationStatus": "CONFIRMED"
      }
    }
  ]
}
```

`properties` хватает на метку и короткую карточку по клику; полная карточка — переход на `/events/:id`.
Пространственный запрос — нативный SQL на PostGIS в `EventMapRepository`. Фильтры совпадают с лентой:
поменяли `EventSpecifications.feed` — поменяйте и его.

## 2. На что наступают

1. **Порядок `[lon, lat]`** — сначала долгота, как в GeoJSON и MapGL. В RasterJS и Leaflet наоборот.
2. **Долгота за ±180.** Прокрученная по кругу карта отдаёт долготу вроде 200 — бэкенд ответит 400.
   Нормализовать: `((lon + 180) % 360 + 360) % 360 - 180`.
3. **`truncated: true`** — показать «Показаны ближайшие 1000 событий — приблизьте карту».
4. **Не заваливать бэкенд.** Запрос по `moveend` с debounce 500 мс; bbox округлять до 3–4 знаков, иначе
   каждый пиксель сдвига — новый ключ кэша.
5. **Не мигать пустой картой** — `placeholderData: keepPreviousData`.
6. **Даты** — ISO в UTC; «сегодня» и «на выходных» считать в поясе пользователя.

## 3. Фронт

```text
widgets/events-map/
  ui/events-map.tsx          карта ленты, карточка, шкала времени
  ui/my-events-map.tsx       карта моих встреч
  ui/location-picker.tsx     выбор или показ точки
  lib/map-provider.ts        публичные фабрики и выбор движка с откатом
  lib/map-contract.ts        MapProvider, PointPicker, MapPoint, Viewport
  lib/providers/raster.ts    RasterJS
  lib/providers/mapgl.ts     MapGL и @2gis/mapgl-clusterer
  lib/bbox.ts                нормализация и округление области
  lib/geocoder.ts            подсказки адресов и обратное геокодирование (Catalog API 3.0)
```

| Метод                                            | Что делает                                                                                                 |
|--------------------------------------------------|------------------------------------------------------------------------------------------------------------|
| `createMapProvider(container, center?, zoom?)`   | карта; `Promise<MapProvider>`                                                                              |
| `createPointPicker(container, initial, onPick?)` | выбор точки; без `onPick` карта только показывает                                                          |
| `onViewportChange(cb)`                           | сразу и по `moveend` (debounce 500 мс) отдаёт `{fetch, visible}`; `fetch` — область с запасом в пол-экрана |
| `setPoints`                                      | метки: вид спорта, время, «я записан», приглушённые вне окна времени; кластеры радиусом 56 px              |
| `onPointClick`, `focus(point \| null)`           | клик и подсветка метки                                                                                     |
| `setHome(point \| null)`                         | дом — некликабельный, не попадает в кластеры                                                               |
| `destroy`                                        | освободить карту и маркеры                                                                                 |

Каждая инициализация создаёт свой вложенный контейнер — так React StrictMode не монтирует карту дважды.

## 4. Движок и ключ

| Переменная           | Значения                                     |
|----------------------|----------------------------------------------|
| `VITE_2GIS_KEY`      | ключ 2ГИС; без него вместо карты — подсказка |
| `VITE_2GIS_MAP`      | `raster` (по умолчанию) или `mapgl`          |
| `VITE_2GIS_STYLE_ID` | ID стиля из Редактора 2ГИС, только для MapGL |

Сравнить на одной сборке: `?map=mapgl` или `?map=raster` в адресе, query главнее env.

- Ключу для MapGL нужен отдельный доступ к **MapGL JS API** в кабинете 2ГИС, для отката — ещё к RasterJS;
  геокодер работает через Catalog API. Ограничьте ключ доменом стенда и `localhost`.
- MapGL подключается только при выборе MapGL. На загрузку SDK и инициализацию — по 15 секунд. Не
  загрузилась, нет WebGL, не подошёл ключ или стиль — `console.warn` и автоматически RasterJS.
- Vite вшивает `VITE_*` при сборке: после смены нужна пересборка фронта (в деве — перезапуск
  `make front`). Env уже собранного образа карту не меняет.

**Стиль.** Основной — «Движ — жёлтый» в Редакторе 2ГИС:
`VITE_2GIS_STYLE_ID=6b1d384b-64e6-4b48-b819-f43c95550961`, правится в Редакторе без пересборки.
Плоский 2D: без 3D-зданий, иконок POI, транспорта и рельефа.

| Элемент                                     | Цвет                                                                          |
|---------------------------------------------|-------------------------------------------------------------------------------|
| фон, суша                                   | `#ffe873`                                                                     |
| дома: жилые / прочие / школы / промышленные | `#b5d9ff` / `#ffcba4` / `#ffbfd5` / `#cbc3ff`, контур `#13142b` с 15 масштаба |
| магистрали / обводка                        | `#b8f01c` / `#13142b`                                                         |
| улицы / обводка                             | `#ffffff` / `#a79cf2`                                                         |
| парки и острова                             | `#4fcf98` с 12 масштаба                                                       |
| вода                                        | `#74c2ff`                                                                     |

Без ID карта берёт запасной стиль из `frontend/public/map-style/`. Он собирается из экспорта Редактора:
`node scripts/build-map-style.mjs <папка экспорта>` — перекрашивает по палитре в начале скрипта, выкидывает
лишние слои и шрифты (~3 МБ вместо ~22).

## 5. Создание мероприятия

Очной встрече нужны `lat` и `lon`: без них `400 «Отметьте место на карте»`, только одно из двух —
`400 «Укажите и широту, и долготу»`. У онлайн-встречи координаты не сохраняются. В форме — `LocationPicker`:
клик по карте или подсказка адреса 2ГИС.

---

## 6. Проверка руками

1. Лента с `?map=raster`, затем с `?map=mapgl`: метки, серые точки, кластеры и дом на месте.
2. Двигать и приближать: запросы раз в 500 мс, внутри запаса области новых нет; фильтры обновляют точки
   без пересоздания карты.
3. Клик по встрече, кластеру и строке шкалы времени: карточка, приближение, подсветка.
4. Карта моих встреч, выбор места кликом и подсказкой, мини-карта в карточке встречи.
5. Заблокировать в DevTools `mapgl.2gis.com/api/js/v1` и открыть `?map=mapgl`: предупреждение в консоли и
   рабочая RasterJS.
