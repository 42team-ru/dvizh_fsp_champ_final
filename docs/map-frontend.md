# Карта событий: провайдеры и API

Карта ленты и карта моих встреч используют `MapProvider`, выбор места — `PointPicker`. Данные: `GET /api/events/map` (Orval-хук `useEventsMap`). Два движка 2ГИС переключаются внутри адаптера; компоненты и геокодер работают с координатами `[lon, lat]`.

## Что делает бэк

- Отдаёт **опубликованные очные** события, у которых точка внутри видимой области карты и **начало** в окне `[from, to]`.
- Кластеры **не считает**: отдаёт точки, группирует их фронт (RasterJS — экранная кластеризация, MapGL — `@2gis/mapgl-clusterer`). Про зум бэк не знает.
- Фильтры те же, что у ленты: `searchText`, `sportId`, `level` (событие уровня «Любой» подходит под любой уровень), `joinMode`. `format` не нужен: онлайн-событий на карте нет.
- Максимум 1000 точек, ближайшие по времени. Если в области больше, приходит `truncated: true`.
- Ответ — стандартный GeoJSON `FeatureCollection`. Его без переделки понимают 2ГИС, Leaflet и MapLibre.

## Запрос

```
GET /api/events/map?minLon=92.7&minLat=55.9&maxLon=93.1&maxLat=56.1
                   &from=2026-10-20T00:00:00Z&to=2026-10-27T00:00:00Z
                   &sportId=…&level=BEGINNER&joinMode=FREE&searchText=бег
```

| Параметр | Обяз. | Что это |
|---|---|---|
| `minLon`, `minLat` | да | юго-западный угол экрана (долгота, широта) |
| `maxLon`, `maxLat` | да | северо-восточный угол |
| `from` | нет | ISO-время. По умолчанию «сейчас»; если передать прошлое, бэк всё равно начнёт с «сейчас» |
| `to` | нет | ISO-время. По умолчанию `from + 30 дней` |
| `searchText`, `sportId`, `level`, `joinMode` | нет | как в ленте (`EventsListParams`) |

Ошибки (400, `ProblemDetail`, поле `detail` показывать как есть):
- нет области или значения вне диапазона (lon −180…180, lat −90…90);
- `minLat > maxLat`;
- `to` раньше `from` или в прошлом.

`minLon > maxLon` — **не ошибка**: так выглядит область через 180-й меридиан (Чукотка), бэк сам ищет в двух прямоугольниках.

## Ответ

```json
{
  "type": "FeatureCollection",
  "truncated": false,
  "limit": 1000,
  "features": [{
    "type": "Feature",
    "id": "a81c3d24-…",
    "geometry": { "type": "Point", "coordinates": [92.889, 56.0097] },
    "properties": {
      "id": "a81c3d24-…",
      "title": "Утренняя пробежка по набережной",
      "sport": { "id": "…", "name": "Бег", "slug": "running", "custom": false },
      "startAt": "2026-10-20T00:00:00Z",
      "endAt": "2026-10-20T01:00:00Z",
      "address": "Красноярск, Центральная набережная, у Часовни",
      "level": "BEGINNER",
      "joinMode": "FREE",
      "participantsCount": 2,
      "capacity": null,
      "myRegistrationStatus": "CONFIRMED"
    }
  }]
}
```

Типы: `EventMapResponse`, `EventMapFeature`, `EventMapProperties`, `PointGeometry`, `EventsMapParams` в `@/shared/api/generated/core/appAPI.schemas`.

`properties` хватает на маркер (цвет или иконка по `sport.slug`, отметка «я записан» по `myRegistrationStatus`) и на короткую карточку по клику. Полная карточка — переход на `/events/:id`, второй запрос не нужен.

## Грабли (прочитай обязательно)

1. **Порядок координат `[lon, lat]`** — сначала долгота. Так в GeoJSON и в 2ГИС. В Leaflet наоборот (`[lat, lng]`).
2. **`null`, а не `undefined`.** В сгенерированных типах необязательные поля описаны как `endAt?: string`, но бэк присылает `"endAt": null`. Это касается всего API, не только карты. Проверяй через `!= null` или `??`, а не через `=== undefined`.
3. **Долгота за ±180.** Если карту прокрутить по кругу, 2ГИС может вернуть долготу вроде 200 → бэк ответит 400. Нормализуй перед запросом: `((lon + 180) % 360 + 360) % 360 - 180`. Если после этого `minLon > maxLon` — так и отправляй, это нормально.
4. **`truncated: true`** — показывай плашку «Показаны ближайшие 1000 событий — приблизьте карту».
5. **Не заваливай бэк запросами.** Запрашивай по `moveend` с debounce 500 мс, а не на каждом кадре анимации. Bbox округляй до 3–4 знаков, иначе каждый пиксель сдвига — новый ключ кэша TanStack Query.
6. **Не мигай пустой картой.** Держи `placeholderData: keepPreviousData` в хуке, чтобы старые точки висели, пока грузятся новые.
7. **Даты.** `from`/`to` — ISO-строки в UTC (`date.toISOString()`). «Сегодня» и «на выходных» считай в часовом поясе пользователя и потом переводи в UTC.

## Схема фронта (FSD)

```text
widgets/events-map/
  ui/events-map.tsx         # карта ленты, карточка, док времени
  ui/my-events-map.tsx      # карта моих встреч
  ui/location-picker.tsx    # выбор или показ точки
  lib/map-provider.ts      # публичные фабрики и выбор движка с fallback
  lib/map-contract.ts      # MapProvider, PointPicker, MapPoint, Viewport
  lib/map-utils.ts         # общий HTML меток и геометрия fetch-области
  lib/providers/raster.ts  # RasterJS: loader.js, DG.divIcon, [lat, lng] внутри SDK
  lib/providers/mapgl.ts   # MapGL: load(), HtmlMarker, Clusterer, [lon, lat]
  lib/map-pins.css         # общие метки Memphis через CSS-токены
  lib/bbox.ts              # нормализация и округление bbox → EventsMapParams
  lib/geocoder.ts          # Catalog API 3.0: подсказки и обратное геокодирование
```

### Контракт адаптера

Публичный импорт — `lib/map-provider.ts`. `createMapProvider(container, center?, zoom?)` возвращает `Promise<MapProvider>`; `createEventsMap` — совместимое имя той же фабрики для существующих экранов. `createPointPicker(container, initial, onPick?)` возвращает `Promise<PointPicker>`. Координаты снаружи всегда `[lon, lat]`; RasterJS переставляет их на границе SDK.

- `onViewportChange(cb)` сразу сообщает `{ fetch, visible }`, дальше — по `moveend` с debounce **500 мс**. `fetch` расширен на половину ширины/высоты экрана в каждую сторону и остаётся прежним, пока видимая область помещается в нём. Возвращаемая функция отписывает обработчик.
- `setPoints` обновляет метки: вид спорта, время или `note`, отметка подтверждённой записи, приглушённые события вне окна времени. Серые и цветные точки кластеризуются раздельно с радиусом 56 px. Клик по кластеру приближает карту.
- `onPointClick` передаёт исходный `MapPoint`. `focus(point)` приближает и подсвечивает выбранную метку; `focus(null)` снимает выделение. В MapGL выбранная метка выводится поверх кластеров.
- `setHome(point | null)` показывает отдельный некликабельный дом, который не попадает в кластеры.
- `PointPicker.setPoint` ставит или убирает точку; `show` ставит точку и приближает. Без `onPick` карта места заблокирована для жестов пользователя.
- `destroy` освобождает карту, маркеры и контейнер. Отдельный вложенный контейнер на каждую инициализацию защищает от двойного монтирования React StrictMode.

### Выбор движка и ключ

В корневом `.env` (шаблон — `.env.example`):

```dotenv
VITE_2GIS_KEY=ваш_ключ
VITE_2GIS_MAP=raster
VITE_2GIS_STYLE_ID=
```

| Переменная | Значения и поведение |
|---|---|
| `VITE_2GIS_KEY` | Публичный ключ 2ГИС; без ключа экраны показывают существующую подсказку вместо карты |
| `VITE_2GIS_MAP` | `raster` (по умолчанию) или `mapgl`; пустое/неизвестное значение означает `raster` |
| `VITE_2GIS_STYLE_ID` | Необязательный идентификатор стиля **MapGL**. Передаётся как `style` вместе со `styleZoom` начального масштаба; без ID — стандартный стиль MapGL. RasterJS его не использует |

Для сравнения на одной сборке открыть, например, `/?map=mapgl` и `/?map=raster`. Query-параметр перекрывает env; неизвестный `map` игнорируется. После смены query перезагрузить страницу; параметр действует и для мини-карты, и для моих встреч на текущей странице.

Для **MapGL JS API ключу нужен отдельный доступ к MapGL в [кабинете 2ГИС](https://platform.2gis.ru/)**. Доступа только к RasterJS недостаточно. Для автоматического отката у того же ключа должен оставаться доступ к RasterJS; геокодер использует Catalog API. Ограничить ключ разрешёнными доменами, включая `localhost` и домен стенда.

SDK подключается через `load()` из `@2gis/mapgl` (канал API `/v1`, рекомендованный 2ГИС), кластеризация — `@2gis/mapgl-clusterer`; оба пакета импортируются только при выборе MapGL. Фабрика проверяет `isSupported()`, дожидается первой отрисовки (`idle`), обрабатывает `styleloaderror` и потерю WebGL-контекста во время инициализации. На загрузку SDK и инициализацию карты отведено по 15 секунд. При ошибке загрузки/инициализации, неподходящем ключе или отсутствии WebGL: `console.warn`, очистка неудачной карты, затем RasterJS с теми же параметрами. Если недоступен и RasterJS, экран использует прежнее сообщение об ошибке. После успешной инициализации переключение при последующих сетевых сбоях не выполняется.

Dev-сервер подмешивает `VITE_*` из корневого `.env`; `frontend/.env` главнее. `docker compose` передаёт эти три переменные в аргументы сборки `frontend/Dockerfile`; GitHub Actions — из одноимённых secrets. Vite вшивает их **при сборке**: после изменения env нужна пересборка фронта (в деве — перезапуск dev-сервера). Настройка env у уже собранного Caddy-образа карту не переключает.

Зависимости закреплены без `^`/`~`. Установка и обновление `yarn.lock`:

```bash
cd frontend
yarn add --exact @2gis/mapgl@1.78.1 @2gis/mapgl-clusterer@2.5.2
yarn typecheck
yarn build
```

Если окружение не имеет доступа к npm, выполнить эти команды в окружении с сетью перед сборкой с `--frozen-lockfile`.

### Свой стиль Memphis

1. Открыть [styles.2gis.com](https://styles.2gis.com), войти и создать стиль на основе стандартного.
2. Настроить фон, воду, зелень, дороги, здания и подписи по таблице ниже; проверить читаемость на масштабах города и квартала. Метки событий оформляются отдельно через `map-pins.css` и токены приложения.
3. Сохранить стиль: **Мои стили → Поделиться → Идентификатор стиля**.
4. Скопировать ID в `VITE_2GIS_STYLE_ID`, задать `VITE_2GIS_MAP=mapgl` и пересобрать фронт. Передавать именно ID, а не ссылку на редактор.

Рекомендуемая палитра из `frontend/src/app/styles/app.css`. В редакторе задаются hex, а компоненты продолжают использовать CSS-токены:

| Элемент карты | Токен | Hex |
|---|---|---|
| Фон / суша | `--paper` | `#f6f4ff` |
| Вода | `--sky` | `#9ed3ff` |
| Парки / зелень | `--mint-soft` / `--lime-soft` | `#d7f3e6` / `#f0fac2` |
| Дороги, заливка | `--card` | `#ffffff` |
| Дороги, обводка | `--ink-muted` | `#6a6c88` |
| Здания | `--lavender` | `#e6e3f5` |
| Основные подписи | `--ink` | `#13142b` |
| Второстепенные подписи / ореол | `--ink-muted` / `--card` | `#6a6c88` / `#ffffff` |

Справочники: [MapGL и npm loader](https://docs.2gis.com/ru/mapgl/start/first-steps), [HTML-кластеризация](https://docs.2gis.com/ru/mapgl/objects/clustering), [MapOptions и события](https://docs.2gis.com/ru/mapgl/reference/interface).

## Создание события: координаты стали обязательными

- Для **очного** события `lat` и `lon` обязательны. Без них бэк отвечает 400 «Отметьте место на карте», а если пришло только одно из двух — «Укажите и широту, и долготу».
- У **онлайн**-события координаты игнорируются: бэк их не сохраняет.
- Значит, в форму создания и редактирования нужен выбор точки: мини-карта с маркером (клик или перетаскивание) и/или геокодер 2ГИС по введённому адресу. В `EventRequest` отправлять `lat` и `lon` числами.
- Форма использует `LocationPicker` и фабрику `createPointPicker` из `map-provider.ts`; выбор провайдера общий с картой ленты.

## Как проверить руками

1. `make dev`, `DEMO_MODE=true make back`, `make front`. Войти, например, за Анну. Открыть ленту с `?map=raster`, затем с `?map=mapgl`: метки событий, серые точки, кластеры и дом должны сохраниться.
2. Подвигать и приблизить карту: запросы по `moveend` идут с debounce 500 мс, fetch-область не меняется внутри запаса. Фильтры и док времени обновляют точки без пересоздания карты.
3. Кликнуть событие, кластер и строку ленты времени: карточка, приближение и подсветка работают. Дом не кликается и не кластеризуется.
4. Проверить карту моих встреч, выбор места кликом и адресной подсказкой, открытие уже выбранной точки, статичную мини-карту в карточке события.
5. Задать свой ID стиля, перезапустить dev-сервер: MapGL меняет подложку; без ID остаётся стандартная. `?map=raster` возвращает растровую карту.
6. Заблокировать `mapgl.2gis.com/api/js/v1` в DevTools и перезагрузить страницу с `?map=mapgl`: предупреждение в консоли и рабочая RasterJS. Повторить с недоступным стилем, ключом только для RasterJS и отключённым WebGL. При зависшей загрузке ожидать до 15 секунд на каждый этап.
7. Уйти со страницы во время загрузки и вернуться (также в StrictMode): лишних контейнеров/карт быть не должно.
