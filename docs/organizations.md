# Организации

Организация — аккаунт роли `ORG`: клуб, кружок, федерация, компания. Она заполняет анкету, проходит
допуск у администратора и после этого публикует встречи без повторной модерации.

---

## 1. Допуск

```
анкета → PENDING → APPROVED | REJECTED | REVISION
```

| Действие                                    | Итог                                         |
|---------------------------------------------|----------------------------------------------|
| первая анкета                               | `PENDING`                                    |
| правка после `REJECTED` или `REVISION`      | снова `PENDING`                              |
| правка `PENDING` или `APPROVED`             | статус не меняется                           |
| админ одобряет                              | `APPROVED`                                   |
| админ отклоняет или возвращает на доработку | `REJECTED` / `REVISION`, причина обязательна |

Отдельной кнопки «отправить» нет: `PUT /api/organizations/me` и есть заявка. В анкете нужен хотя бы
один вид спорта (до десяти) и хотя бы один контакт: телефон, почта, Telegram, VK, WhatsApp, MAX или сайт.
Документы прикладываются файлом (PDF, JPG, PNG до 10 МБ, до 10 штук) — их смотрит админ.

Админ может пересмотреть решение в любую сторону. Если допуск отозван, встречи организации пропадают из
ленты, карты и профиля, запись и управление ими закрыты (`409`). При повторном одобрении всё возвращается.

| Что                 | `PENDING`, `REJECTED`, `REVISION`                            | `APPROVED` |
|---------------------|--------------------------------------------------------------|------------|
| Публиковать встречи | нет, `403` и пояснение в `GET /api/events/create-permission` | да, сразу  |
| Публичная страница  | `404`                                                        | открыта    |
| В каталоге          | нет                                                          | да         |

---

## 2. Каталог

`/orgs` — допущенные организации. Вкладка «Все»: поиск по названию и описанию, фильтры по городу и виду
спорта. Вкладка «Мои»: подписки и клубы, где человек был, с пометкой причины.

---

## 3. Публичная страница

`/orgs/:id` открывается двумя запросами: профиль (`GET /api/organizations/{id}`) и сводка (`/overview`). Архив встреч и
галерея подгружаются по действию посетителя, со своей пагинацией.

Учитываются только опубликованные встречи и непрерванные занятия.

| Показатель          | Как считается                                                                                                |
|---------------------|--------------------------------------------------------------------------------------------------------------|
| Проведённые встречи | завершившиеся занятия; без `endAt` конец = начало + 2 часа. Серия — несколько занятий                        |
| Участники за год    | разные участники занятий за последние 365 дней: у разовых — подтверждённые записи, у серий — отметки на дату |
| Возвращаемость      | доля участников с 2+ посещениями; при выборке меньше пяти человек не показывается                            |
| Фото                | фото мероприятий и альбомов участников; «из M встреч» — число разных мероприятий с фото                      |
| График              | текущий месяц и 11 предыдущих                                                                                |
| Расписание          | ближайшее занятие на каждый день недели в следующие 28 дней, по местному времени                             |
| Команда             | авторы и соорганизаторы встреч клуба, кроме самого аккаунта клуба                                            |
| Места               | четыре самых частых адреса                                                                                   |

Пустые блоки (нет команды, расписания, документов) скрываются. Отзывов и рейтинга нет — в продукте нет
отзывов.

**Награды** клуба — на странице, с датой получения или прогрессом («64 из 100»).
Правила: [economy.md](economy.md#4-награды-организаций).

## 4. Подписки

Подписаться на анонсы может только `USER`, аккаунты `ORG` и `ADMIN` получают `409`. Повторный запрос
безопасен: команды берут блокировку организации, пара `(organization_id, user_id)` уникальна.

Когда организация публикует встречу, подписчики получают уведомление `ORG_NEW_EVENT` (категория
«Организации») со ссылкой на встречу. Ключ `org-new-event:{eventId}` защищает от повторов.

## 5. API

| Метод        | Путь                                                              | Что                                                                           |
|--------------|-------------------------------------------------------------------|-------------------------------------------------------------------------------|
| GET          | `/api/organizations?searchText=&city=&sportId=&mine=&page=&size=` | каталог                                                                       |
| GET          | `/api/organizations/cities`                                       | города каталога                                                               |
| GET          | `/api/organizations/{id}`                                         | профиль, награды, документы, контакты; не допущена — 404                      |
| GET          | `/api/organizations/{id}/overview`                                | показатели, график, команда, места, расписание, первые страницы встреч и фото |
| GET          | `/api/organizations/{id}/meetings?sportId=&page=&size=`           | архив встреч                                                                  |
| GET          | `/api/organizations/{id}/photos?page=&size=`                      | галерея                                                                       |
| POST, DELETE | `/api/organizations/{id}/subscription`                            | подписка; ответ — состояние, число подписчиков и до четырёх аватаров          |
| GET, PUT     | `/api/organizations/me`                                           | своя анкета; не `ORG` — 403, без анкеты — 404                                 |
| PUT, DELETE  | `/api/organizations/me/logo`                                      | логотип                                                                       |
| POST, DELETE | `/api/organizations/me/documents`                                 | документы для проверки                                                        |
| GET          | `/api/organizations/featured`                                     | «Организация месяца» или пустой ответ                                         |

Страница от нуля, размер 1–100. Все запросы требуют входа.
