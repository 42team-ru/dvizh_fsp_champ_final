# Виды спорта в админке

«Админка» → «Виды спорта»: справочник, картинки, проверка видов, которые ввели пользователи, слияние
дублей.

---

## 1. Статусы

| Статус    | Что значит                                                                                           |
|-----------|------------------------------------------------------------------------------------------------------|
| `ACTIVE`  | вид из справочника или одобренный админом                                                            |
| `PENDING` | свой вид пользователя, создан вместе с мероприятием: им уже можно пользоваться, админ ещё не смотрел |
| `HIDDEN`  | отключён: нет в поиске, новое мероприятие с ним — 400, старые остаются                               |
| `MERGED`  | слит с другим видом (`mergedIntoId`): мероприятия, интересы, анкеты и скрытия перенесены             |

Вид, который добавил сам админ, сразу `ACTIVE`; с `published=false` — черновик `HIDDEN`. Мероприятие с
именем слитого вида получает целевой вид.

---

## 2. Картинка

PNG, квадрат от 256×256, до 2 МБ; формат проверяется по сигнатуре. Хранится в `files` (`SPORT_IMAGE`),
точка фокуса — голова персонажа, в процентах (`imageFocusX/Y`). Без загруженной картинки виду отдаётся
встроенная иллюстрация `sport-images/<slug>.webp` или общая заглушка ([sport-images.md](sport-images.md)).
Замена и удаление стирают прежний файл.

---

## 3. API

Тег `admin`, только `ADMIN`.

| Метод       | Путь                                                              | Что                                                        |
|-------------|-------------------------------------------------------------------|------------------------------------------------------------|
| GET         | `/api/admin/sports?status=&withoutImage=&searchText=&page=&size=` | список; `status` можно повторять                           |
| GET         | `/api/admin/sports/counts`                                        | счётчики вкладок                                           |
| POST        | `/api/admin/sports?name=&focusX=&focusY=&published=`              | добавить; multipart `file` необязателен                    |
| PUT         | `/api/admin/sports/{id}`                                          | переименовать                                              |
| PUT, DELETE | `/api/admin/sports/{id}/image`                                    | загрузить или убрать PNG                                   |
| POST        | `/api/admin/sports/{id}/approve`                                  | одобрить; только `PENDING`                                 |
| POST        | `/api/admin/sports/{id}/hide`, `/restore`                         | отключить с причиной, вернуть                              |
| POST        | `/api/admin/sports/{id}/merge`                                    | `{targetId, reason?}` — слить с другим видом               |
| DELETE      | `/api/admin/sports/{id}`                                          | удалить; есть ссылки (мероприятия, интересы, анкеты) — 409 |

Видов десятки, поэтому список фильтруется в памяти, и фильтр «без картинки» учитывает встроенные
иллюстрации.
