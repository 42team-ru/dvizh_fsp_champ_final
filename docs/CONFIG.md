# Конфигурация

Все настройки — переменные окружения. Значения по умолчанию лежат в
[`backend/src/main/resources/application.yml`](../backend/src/main/resources/application.yml) и подходят
для локального запуска. Для `docker compose` переменные задаются в `.env` рядом с `docker-compose.yml`
или прямо в командной строке. Любая правка требует перезапуска.

---

## 1. Сервер и порты

| Переменная       | Дефолт                  | Назначение                                                                                                   |
|------------------|-------------------------|--------------------------------------------------------------------------------------------------------------|
| `PORT`           | 8080                    | внешний HTTP-порт Caddy                                                                                      |
| `HTTPS_PORT`     | 8443                    | внешний HTTPS-порт Caddy                                                                                     |
| `DOMAIN`         | `:80`                   | домен; при настоящем домене Caddy сам получает сертификат Let's Encrypt (нужны `PORT=80` и `HTTPS_PORT=443`) |
| `APP_PUBLIC_URL` | `http://localhost:8080` | адрес стенда: ссылки в «Поделиться», QR-кодах и уведомлениях                                                 |
| `CORS_ORIGINS`   | `http://localhost:5173` | откуда фронт ходит в API при раздельном запуске                                                              |

## 2. Данные

| Переменная                       | Дефолт                                 | Назначение                                                                            |
|----------------------------------|----------------------------------------|---------------------------------------------------------------------------------------|
| `DB_URL`                         | `jdbc:postgresql://localhost:5440/app` | PostgreSQL с PostGIS                                                                  |
| `DB_USER`, `DB_PASSWORD`         | `app` / `app`                          | доступ к базе; **сменить вне демо**                                                   |
| `STORAGE_TYPE`                   | `s3`                                   | `s3` — MinIO или любой S3; `memory` — файлы в памяти процесса, пропадают при рестарте |
| `S3_ENDPOINT`                    | `http://localhost:9440`                | адрес S3                                                                              |
| `S3_ACCESS_KEY`, `S3_SECRET_KEY` | `app` / `app-secret-dev`               | ключи S3; **сменить вне демо**                                                        |
| `S3_BUCKET`                      | `app-files`                            | бакет для фото и документов                                                           |

Схема базы создаётся миграциями Flyway при старте. Миграции только вперёд, применённые не правятся.

## 3. Вход

| Переменная   | Дефолт     | Назначение                                    |
|--------------|------------|-----------------------------------------------|
| `JWT_SECRET` | dev-строка | подпись JWT; **обязательно сменить вне демо** |

Сроки жизни: `access_token` — 15 минут, `refresh_token` — 14 дней.

## 4. Демо-режим

| Переменная      | Дефолт            | Назначение                                                             |
|-----------------|-------------------|------------------------------------------------------------------------|
| `DEMO_MODE`     | `true`            | кнопки демо-входа на странице логина и создание демо-данных при старте |
| `DEMO_PASSWORD` | `demo-password-1` | пароль всех демо-аккаунтов                                             |

Демо-данные создаются только на пустой базе: если аккаунт `admin` уже есть, сид ничего не делает.
Чтобы пересоздать, сотрите базу: `docker compose down -v`, а для `make dev` —
`docker compose -f docker-compose.dev.yml down -v`.

Фото для демо лежат в `backend/src/main/resources/demo-photos` и готовятся скриптом
`python scripts/demo_photos.py` (`fetch`, `sheet`, `drop`, `check`). Без них сид работает, просто
у встреч не будет фото.

На публичном стенде с настоящими пользователями `DEMO_MODE` выключается.

## 5. Карта 2ГИС

| Переменная           | Дефолт   | Назначение                                                                                          |
|----------------------|----------|-----------------------------------------------------------------------------------------------------|
| `VITE_2GIS_KEY`      | пусто    | ключ API 2ГИС: карта, подсказки адресов, маршруты «когда выходить». Подставляется при сборке фронта |
| `VITE_2GIS_STYLE_ID` | пусто    | свой стиль карты из Редактора 2ГИС                                                                  |
| `VITE_2GIS_MAP`      | `raster` | движок карты                                                                                        |

Без ключа карта и подсказки адресов не работают. Онлайн-встречи создавать можно, очные — нет:
им нужны координаты.

## 6. Модерация

| Переменная                      | Дефолт (compose) | Назначение                                                                 |
|---------------------------------|------------------|----------------------------------------------------------------------------|
| `MODERATION_LLM_ENABLED`        | `true`           | фоновая проверка нейросетью Qwen3.5-0.8B (llama.cpp)                       |
| `MODERATION_CLASSIFIER_ENABLED` | `true`           | классификатор токсичности rubert-tiny-toxicity                             |
| `MODERATION_AUTO_HIDE`          | `true`           | скрывать сообщение без админа, если серьёзное нарушение видят двое из трёх |

Вне Docker оба источника по умолчанию выключены, работает только словарь. Словари — в
`backend/src/main/resources/moderation/`. Подробнее: [moderation.md](moderation.md).

## 7. Уведомления

| Переменная                                                               | Дефолт             | Назначение                     |
|--------------------------------------------------------------------------|--------------------|--------------------------------|
| `NOTIFICATIONS_TIME_ZONE`                                                | `Asia/Krasnoyarsk` | часовой пояс напоминаний       |
| `NOTIFICATIONS_SCHEDULING_ENABLED`                                       | `true`             | фоновые напоминания о встречах |
| `TELEGRAM_ENABLED`                                                       | `false`            | доставка в Telegram            |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET` | пусто              | бот и секрет вебхука           |

Email и MAX в демо подключаются, но ничего не отправляют. Подробнее: [notifications.md](notifications.md).
