# Фронтенд

React Router 7 в режиме SPA (`ssr: false`), Vite, Tailwind 4, shadcn/ui. Исходники `frontend/src` — по
FSD:

| Слой       | Что                                                                 |
|------------|---------------------------------------------------------------------|
| `app`      | маршруты (`routes.ts`, тонкие файлы в `routes/`), провайдеры, стили |
| `pages`    | страницы                                                            |
| `widgets`  | крупные блоки страниц                                               |
| `features` | действия пользователя                                               |
| `entity`   | модели предметной области                                           |
| `shared`   | `components/ui` (shadcn), `api` (клиент Orval), `lib`               |

- Данные — только через хуки Orval ([orval.md](orval.md)).
- Подписи статусов (текст, цвет, иконка) — в одном месте: `shared/lib/statuses.ts`.
- Цвета и тени — токены в `app/styles/app.css` (`bg-ink`, `shadow-hard`), без hex в компонентах.
- Тексты интерфейса — русские.

## 1. Спортивный фон страниц

`shared/components/ui/memphis-background.tsx` рисует на фоне инвентарь: мячи, гантели, кубок. Раскладка
посчитана заранее и лежит в `memphis-layouts.json` — по странице и ширине с шагом 40 px, поэтому фон стоит
с первого кадра и не перекладывается при переходах. У каждой страницы свой `seed`. Без готовой раскладки
под ширину фон считает её на месте.

Поменяли вёрстку страницы с фоном — пересобрать раскладки на запущенном демо-стенде (`make dev`,
`make back`, `make front`):

```bash
cd frontend && yarn prebuild:memphis
```

## 2. PWA

Приложение устанавливается на телефон и компьютер, оболочка открывается без сети.

`public/sw.js` написан вручную, без зависимостей. После `react-router build` скрипт
`scripts/prepare-pwa.mjs` добавляет в `build/client/sw.js` список ресурсов и версию кеша по их содержимому
— новая сборка сама обновляет SW.

| Что                             | Стратегия                                              |
|---------------------------------|--------------------------------------------------------|
| навигация                       | сеть, при её отсутствии — предзагруженный `index.html` |
| `/assets/*` с хешами            | кеш                                                    |
| `/api/*`, 2ГИС, внешние сервисы | не кешируются                                          |

После активации новой версии появляется «Доступна новая версия» → «Обновить». В `yarn dev` SW не
регистрируется и снимается, чтобы не мешать HMR.

### Проверка

```bash
cd frontend && yarn build && yarn preview    # http://localhost:4173
```

С телефона нужен HTTPS: по HTTP и IP Service Worker не работает. `/api` в preview не проксируется —
сценарии со входом проверяются через Caddy с бэкендом.

Chrome DevTools → Application:

1. **Manifest** — «Движ — спорт рядом», standalone, иконки 192/512 и maskable, три ярлыка.
2. **Service Workers** — `/sw.js`, scope `/`, activated; в Cache Storage — `dvizh-pwa-v1-<хеш>`.
3. **Offline** — `/feed` и прямые ссылки открывают оболочку; данные, вход и карта без сети недоступны.
4. **Установка** — меню аккаунта → «Установить приложение»; в iOS Safari — «Поделиться → На экран
   Домой». В установленном окне пункт скрыт.
5. **Обновление** — пересобрать при открытой вкладке, нажать Update у SW: появится тост «Обновить».

Иконки генерируются из `public/icon.svg`: `python3 frontend/scripts/generate-pwa-icons.py` (нужны
librsvg и Cairo). Фон — `--paper` (`#F6F4FF`), цвет темы — `--ultramarine` (`#4B3FE0`); при смене токенов
синхронизировать манифест, `root.tsx` и генератор.
