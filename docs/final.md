# Финал хакатона

Для последнего дня: сначала проверка, потом очистка репозитория от служебных файлов. Сам этот файл
удаляется при очистке.

## 1. Проверка

- [ ] С нуля в пустой папке: `git clone <репозиторий> /tmp/check && cd /tmp/check && docker compose up --build`,
  затем <http://localhost:8080> открывается, работают кнопки демо-входа.
- [ ] Все шесть сценариев из README проходят руками; `make postman` — без ошибок.
- [ ] Сайт открывается в обычном и приватном окне, в консоли нет ошибок.
- [ ] На демо-сервере `DEMO_MODE=true`.
- [ ] README отражает реальность, ссылки в `docs/` не битые.

## 2. Очистка репозитория

Делает один человек, когда остальные уже запушили. Предупредите команду: после `git pull` служебные файлы
пропадут у всех.

```bash
git checkout main && git pull
node scripts/finalize.mjs             # dry-run: что будет убрано
node scripts/finalize.mjs --apply     # один обычный коммит
git show --stat HEAD                  # проверить глазами
git push origin main                  # без --force
```

Убираются `CLAUDE.md`, `AGENTS.md`, `.claude/`, `.codex/`, `frontend/.mcp.json`, этот файл, проверки
коммитов (`.githooks`, `scripts/hygiene.mjs`) и сам скрипт. История не переписывается.

После пуша:

- [ ] CI зелёный: `gh run watch`
- [ ] сайт работает: `curl https://<домен>/api/ping`
- [ ] `git ls-files` не содержит служебных файлов
