## Кнопка: финальная очистка репозитория
Делает **один человек**, когда все остальные уже запушили свои изменения. Перед этим сообщите команде: после `git pull` служебные файлы у них пропадут из рабочей папки.

```bash
git checkout main && git pull           # актуальный main, рабочая копия чистая
node scripts/finalize.mjs               # 1. dry-run: посмотреть, что будет сделано
node scripts/finalize.mjs --apply       # 2. применить: один обычный коммит
git show --stat HEAD                    # 3. проверить коммит глазами
git push origin main                    # 4. обычный push, без --force
```
Что уходит из репозитория:
- служебные файлы: инструкции для агентов, их настройки, настройки MCP во фронте, этот файл и сам скрипт очистки (у вас на диске они остаются, вне репозитория; с флагом `--purge` удаляются и с диска);
- проверки коммитов целиком: `.githooks`, `scripts/hygiene.mjs` и всё, что их подключало (цели `hooks`, `scan`, `junk` в Makefile, скрипт `prepare` в `frontend/package.json`, задача `installGitHooks` в `backend/build.gradle.kts`, строка в `.gitattributes`, раздел в документации);
- локальная настройка `core.hooksPath` снимается.

Остаётся только полезный код: бэкенд, фронт, деплой, тесты, `docs/`.
История не переписывается: в старых коммитах файлы остаются (откатиться на коммит назад можно). Push обычный, без `--force`.

После пуша проверьте:
- [ ] CI на финальном коммите зелёный: `gh run watch`
- [ ] Деплой прошёл, сайт работает: `curl https://ваш-домен/api/ping`
- [ ] `git ls-files` не содержит служебных файлов и скрипта очистки
