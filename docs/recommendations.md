# Рекомендации

Подборка «Вам подойдёт», «Клубы для вас», «Похожие встречи» и кнопка «Не интересно».

| Класс                                 | Что делает                                             |
|---------------------------------------|--------------------------------------------------------|
| `RecommendationService`               | сценарии: подборка, похожие, клубы, скрытие            |
| `RecommendationSignals`               | сбор сигналов о человеке одним запросом на вид сигнала |
| `EventScorer`                         | формулы признаков                                      |
| `DiversityRanker`                     | порядок с разнообразием (MMR)                          |
| `util/RecommendationMath`, `util/Geo` | затухание, косинус, Жаккар, гаверсинус                 |

Оценка — взвешенная сумма понятных признаков, каждый в `[0, 1]`. Поэтому у карточки есть 1–3 причины («Вы занимаетесь:
футбол», «1,2 км от дома», «Идёт Анна — вы уже занимались вместе»), а `explain`
показывает всю раскладку. Всё считается на каждый запрос из текущих данных: записался, скрыл, поменял
интересы — подборка сразу другая. Запросы — JPQL, работают и на H2.

---

## 1. Кандидаты

Опубликованные мероприятия с занятием в окне `[сейчас + 30 мин, сейчас + 30 дней]`, до 500 ближайших.

Не показываются: свои (автор или соорганизатор), куда уже записан (`CONFIRMED`, `PENDING`, `WAITLISTED`),
с отклонённой заявкой, скрытые мной, разовые без мест, очные дальше `3 × радиус`, мероприятия
организаций с отозванным допуском. Аккаунтам организаций и админу — пустой список: они не записываются.

## 2. Признаки

| Признак                            | Формула                                                            | Вес  |
|------------------------------------|--------------------------------------------------------------------|------|
| `SPORT` — интерес к виду           | `max(p(u,s), 0.6 · maxₜ p(u,t)·sim(t,s))`                          | 0.30 |
| `DISTANCE` — расстояние            | `2^(−(d/R)²)`: 1 рядом, 0.5 на радиусе; онлайн — 0.6               | 0.15 |
| `LEVEL` — уровень                  | «Любой» 0.85, совпал 1, проще 0.6, сложнее 0.4, через ступень 0.05 | 0.12 |
| `TIME` — удобное время             | `0.6·[день] + 0.4·[время суток]`, пополам с привычками             | 0.12 |
| `SOCIAL` — идут знакомые           | `1 − e^(−F/2)`, `F = Σ w(u,v)` по участникам                       | 0.08 |
| `ORGANIZER` — знакомый организатор | `max(ℓ(o), 0.5 · max ℓ(o')·J(o',o))`                               | 0.08 |
| `TRUST` — надёжность               | `h / (h + 5)`, у организации +0.1                                  | 0.05 |
| `POPULARITY`                       | `1 − e^(−n/6)`                                                     | 0.04 |
| `QUORUM` — почти набрали           | 1, если до кворума не хватает 1–3 человек                          | 0.03 |
| `URGENCY` — когда начнётся         | 1 через 6–72 ч; ближе — меньше, дальше `e^(−(t−72)/168)`           | 0.03 |

Если у человека нет данных для признака (нет точки, нет предпочтений), признак выключается, а сумма
делится на веса только включённых. Новичок не проигрывает из-за пустого профиля.

### Интерес к виду спорта

```
r(u,s) = Σ вес_сигнала · 2^(−Δt / 45 дней)
p(u,s) = r(u,s) / max r(u,·)
```

| Сигнал                      | Вес | Затухает |
|-----------------------------|-----|----------|
| вид в профиле               | 3.0 | нет      |
| посещённое занятие          | 1.0 | да       |
| проведённое мероприятие     | 1.0 | да       |
| текущая запись              | 0.8 | да       |
| отклонённая заявка          | 0.5 | да       |
| своё сообщение в обсуждении | 0.3 | да       |
| отменённая запись           | 0.2 | да       |

### Похожесть видов

Косинус по множествам занимающихся (профили и подтверждённые записи), сжатый на малой выборке:

```
sim(s,t) = |A∩B| / √(|A|·|B|) · n / (n + 5),   n = |A∩B|
```

Два случайно совпавших человека виды похожими не делают, двадцать — делают. Так любителю футбола
попадается мини-футбол с причиной «Похоже на ваш интерес: футбол».

### Расстояние

Гаверсинус до точки отсчёта. Точка: `lat/lon` из запроса → дом из предпочтений → покоординатная медиана
последних 10 мест, где человек занимался (медиана устойчива к одной поездке в другой город).
Радиус: из запроса → из предпочтений → 10 км.

### Время

По местному времени занятия: пояс серии, иначе ближайшего крупного города по координатам (`Geo.zoneNear`). Утро 5–11,
день 12–16, вечер — остальное; соседний отрезок суток засчитывается наполовину.
Привычка — гистограмма «7 дней × 3 отрезка» по посещениям со сглаживанием `(n+1)/(max+1)`, учитывается
с трёх посещений.

### Знакомые и организатор

`w(u,v)` — сколько прошедших занятий двое были вместе (разовые — обе записи подтверждены, серии — обе
отметки). Лояльность к организатору `ℓ = 1 − e^(−k/2)`, где k — мои посещения у него. Похожие
организаторы — коэффициент Жаккара их аудиторий со сжатием `n/(n+5)`: «к ним ходят те же люди».

## 3. Итоговая оценка

```
score   = gate · penalty · Σ wᵢ·fᵢ / Σ wᵢ                  (по включённым признакам)
gate    = 0.3, если LEVEL < 0.1 (новичку — встреча для профи), иначе 1
penalty = max(floor, sportFactor^k · Π (1 − similarStrength · sim(x, c) · decay(x)))
sim     = 0.45·[тот же вид, иначе sim(t,s)] + 0.25·[тот же организатор]
        + 0.15·[тот же день недели и время суток] + 0.15·[ближе 3 км]
```

- k — сколько раз человек скрыл встречи этого вида с причиной «Не мой вид спорта» (с тем же затуханием).
- Π — по скрытым встречам x, похожим на кандидата c не меньше `minSimilarity`.
- `floor = 0.35`: похожие на скрытую встречу опускаются, но не пропадают.

Скрытая встреча уходит из подборки, но остаётся в ленте и поиске.

**Причины** — признаки с наибольшим вкладом `wᵢ·fᵢ / Σw`, не меньше 0.03, до трёх. Не прошла ни одна —
«Начнётся через …».

## 4. Порядок: разнообразие и «Попробуйте новое»

Maximal Marginal Relevance — иначе вся первая страница была бы одним клубом:

```
следующий = argmax  λ·score(e) − (1−λ)·max sim(e, уже выбранные),   λ = 0.75
sim       = 0.6·[тот же вид] + 0.3·[тот же организатор] + 0.1·[тот же день]
```

Каждая пятая позиция — `discovery`: лучший кандидат без признака `SPORT` среди видов, с которыми человек
не связан («Попробуйте новое: петанк»). Порядок детерминированный, демо не прыгает.

**Холодный старт.** Нет интересов и истории → `SPORT` и `ORGANIZER` выключены, уровень по умолчанию
«Новичок»: встречи «Любой» и «Для новичков» поднимаются, профи гасятся. Работают расстояние, время,
надёжность, популярность. Слотов `discovery` нет — новое всё.

## 5. Похожие встречи

```
похожесть = 0.45·sim видов + 0.15·уровень + 0.15·место (ядро 5 км)
          + 0.10·время (час ядром 3 ч + тот же день недели)
          + 0.15·общие участники (Жаккар со сжатием n/(n+3))
```

Другие виды — только при `sim ≥ 0.3`. Если у человека есть профиль, оценка умножается на
`0.7 + 0.3·личная оценка`. Затем MMR.

## 6. Клубы для вас

Допущенные организации со встречами в ближайшие 30 дней, кроме своей:

| Признак     | Формула                                                         | Вес  |
|-------------|-----------------------------------------------------------------|------|
| вид спорта  | `Σ p'(s) / √                                                    | виды |` по видам анкеты и встреч, `p'` — с похожими видами | 0.40 |
| расстояние  | до ближайшей очной встречи клуба; без точки — совпадение города | 0.20 |
| надёжность  | `h/(h+5)`, «Организация месяца» +0.2                            | 0.15 |
| активность  | `1 − e^(−n/3)` по встречам в ближайший месяц                    | 0.15 |
| для новичка | доля встреч «Любой» и «Для новичков»; только у новичков         | 0.10 |

Клуб, где человек был 3+ раза, умножается на 0.5 — он уже «свой».

|--------|--------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| GET    | `/api/recommendations/events?lat&lon&radiusKm&sportId&from&to&page&size` | карточки ленты + `score`, `distanceKm`, `reasons`, `discovery`                  |

## 8. Как подкрутить

Все константы — `app.recommendations.*` в `application.yml` (`RecommendationProperties`): `weights.*`,
`scoring.*`, `dismiss.*`, `half-life-days`, `horizon-days`, `discovery-every` (0 — без слотов),
`mmr-lambda`, `max-distance-factor`, `max-candidates`. Сумма весов не обязана быть 1.

Удобнее всего проверять через `explain` у Анны на демо: у неё задан дом, интересы — бег и йога, а турнир
«Ладьи» она уже скрыла («Вы скрыли его из подборки»).

---

## 9. Ограничения

- Считается по всей базе на каждый запрос: на демо — десятки миллисекунд. На десятках тысяч пользователей
  понадобится кэш похожести видов и организаторов с обновлением раз в несколько минут.
- Посещение не подтверждается: «был» = подтверждённая запись или отметка на прошедшем занятии.
- Пояс разового мероприятия — по ближайшему из ~15 крупных городов России.
- Веса подобраны вручную. Для обучения (например, логистической регрессии по «записался / скрыл») нужно
  больше реальных данных.
