# Hackathon template

Java 25 + Spring Boot 4.1 (Gradle Kotlin DSL) · React Router 7 + Vite + Tailwind (yarn) · Postgres 18 alpine · Caddy · Docker.

## Для жюри / демо: одна команда
```bash
docker compose up --build      # нужен только Docker
```
Откроется на http://localhost:8080 (Swagger: `/swagger-ui.html`). Первая сборка 2–3 минуты. Включён демо-режим, пароль у всех `demo-password-1`. На странице входа — кнопки на четыре роли: `anna` (пользователь), `ladya` (одобренная организация), `enisey` (организация ждёт одобрения), `admin`. Для проверки «под другим пользователем» есть ещё `petr` (организатор с заявками) и `olga`, без кнопок — логин вводится в форму.

## Разработка
```bash
make dev     # Postgres (порт 5440) и S3/MinIO (порт 9440, консоль 9441), один раз
make back    # бэкенд  :8080, в своём терминале
make front   # фронт   :5173, в своём терминале
```
Без make: `node scripts/dev.mjs [back|front]` (работает и на Windows).

## Личная галерея

В профиле можно загрузить до 6 фотографий JPG, PNG или WebP по 5 МБ, открыть снимок и удалить его.
Галерея хранится отдельно от аватара; фотографии доступны вошедшим пользователям через публичный профиль API.

## Рекомендации (бэкенд)

Подборка «Вам подойдёт» и «Клубы для вас»: оценка по виду спорта (профиль, история с затуханием, похожие виды),
уровню, расстоянию от дома, удобному времени, знакомым участникам и организаторам, надёжности и кворуму; выдача
разнообразится, каждая 5-я позиция — «Попробуйте новое». У каждой карточки 1–3 причины, «Не интересно» убирает
событие и снижает вид спорта. «Похожие встречи» — на том же движке. Экраны — в работе. Формулы: [docs/recommendations.md](docs/recommendations.md).

## Уведомления

Во вкладке «Активность» — входящие и настройки внешних каналов: Telegram по одноразовой ссылке,
Email и MAX с подключением контакта в демо-режиме (без реальных отправок). Категории сохраняются автоматически.
На главной «Бублик подсказывает», когда выходить на ближайшую встречу: пешком, на автобусе или на машине
по маршрутам 2ГИС (с учётом, ходит ли транспорт), и ставит личное напоминание.
Контракт и настройка Telegram: [docs/notifications.md](docs/notifications.md).
